# Agency — The Constraint Town

[Agency](https://agency.retehost.com) is an open, deterministic simulation of how equal effort can produce unequal outcomes under repeated material shocks. A navigable 3D town shows 120 synthetic households across a year; the laboratory repeats the same model across 1,000 or more seeded worlds.

Everything needed to inspect, reproduce, criticize, and extend the project is included here:

- the full Next.js and React Three Fiber application;
- the deterministic household simulation;
- the browser-based Monte Carlo laboratory;
- a command-line Monte Carlo runner;
- raw reference outcomes in CSV and JSON;
- parameter and operational-definition documentation;
- the Elias Marrow essays that motivated the project.

Secrets, local environment files, Vercel metadata, dependency folders, and build products are intentionally excluded.

## Start locally

Requires Node.js 24 or newer.

```bash
npm ci
npm run dev
```

Then open `http://localhost:3000`. The laboratory is at `/laboratory`.

## Reproduce the 1,000-world reference run

```bash
npm run monte-carlo -- --seed agency-lab-0001 --runs 1000 --mode base --out data/reference/base-1000-worlds
npm run verify:reference
```

The command writes both raw per-world outcomes and aggregate summaries:

- `data/reference/base-1000-worlds.csv`
- `data/reference/base-1000-worlds.json`

Use `--mode layered` to enable transportation, health, access, and education constraints. Change the seed, run count, or output path freely.

## Scientific boundary

This is an inspectable explanatory model, not a forecast and not an empirical estimate of poverty in a real population. Monte Carlo repetition measures uncertainty generated by the stated rules. It does not make those assumptions true.

The control is calibrated to three aggregate statements in *Effort Was Held Constant*: roughly 90% stable at year-end, nearly half experiencing compound failure at some point, and roughly one in twenty-four trapped in compound failure for most of the year. Displacement and broader hardship are model outputs, not claims attributed to the essay.

Read [the methodology](docs/methodology.md), [the parameter register](docs/parameters.md), and [the data dictionary](data/README.md) before interpreting the results.
