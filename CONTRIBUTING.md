# Contributing

Agency is meant to be inspected and challenged.

## Before opening a change

1. Read `docs/methodology.md` and `docs/parameters.md`.
2. Preserve deterministic seeded behavior unless the change explicitly revises the random process.
3. Add or identify a seed that demonstrates any changed behavior.
4. Run `npm run typecheck`, `npm run build`, and `npm run verify:reference`.

If a change intentionally alters the model, regenerate the reference dataset and explain the changed assumptions and results. Never silently tune a parameter to obtain a preferred headline.

## Scientific language

Keep these categories separate:

- assumptions encoded by the model;
- results generated by the model;
- observations from external empirical research;
- claims made by the source essays.

Monte Carlo intervals in this project describe variation among simulated worlds. They are not confidence intervals for a real population.

## Security and privacy

Do not commit credentials, `.env` files, provider metadata, production exports containing private information, or any real-person household data. All residents in this project are synthetic.
